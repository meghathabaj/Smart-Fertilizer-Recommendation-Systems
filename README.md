# 🌱 Smart Fertilizer Recommendation System

A weather-based fertilizer recommendation system developed using Python, Flask, and Streamlit.

## Features
- Recommends NPK fertilizer dosage based on crop type and soil nutrients.
- Fetches real-time temperature and humidity using WeatherAPI.
- Provides crop-specific fertilizer recommendations.

## Technologies Used
- Python
- Flask
- Streamlit
- Pandas
- WeatherAPI
- CSV Dataset

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Create a `.env` file with `WEATHER_API_KEY=your_api_key`
3. Run the backend: `python fertilizer_project.py`
4. Run the frontend: `streamlit run fertilizer_app.py`
